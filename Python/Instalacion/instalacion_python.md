# Instalar Python

Recomendado: 

## Opción 1: Instalar miniconda.

Entra a la dirección web:

https://www.anaconda.com/download/success

Y busca la sección que dice **Miniconda**. Puedes usar el instalador gráfico o la línea de comandos. Sigue las instrucciones anexas segun sea el caso. 

Miniconda instala python y manejadores de entorno como conda, pip y herramientas escenciales.

Nota: Si pregunta si quieres guardar en el Path de Windows acepta. 

## Opción 2: Descarga desde la página

https://www.python.org/

En la sección de descargas busca el instalador de Python y descargalo. Sigue las instrucciones anexas.

Opción 3: Instalar vía terminal (línea de comandos).

### Windows powershell:

```bash
winget install Python.Python.3.14
```

### Linux

```bash
sudo apt update
sudo apt install python3
```
